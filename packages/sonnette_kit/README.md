# sonnette_kit

Embeddable one-to-one video calling for Flutter. Import `package:sonnette_kit/sonnette_kit.dart`, authenticate a `SonnetteClient`, and place `SonnetteCallWidget(client: client)` inside your existing Material application.

The host owns the client lifecycle, credentials and navigation. The widget supplies call controls and video rendering; the controller can also drive a custom UI.

See the [root README](../../README.md) and [integration guide](../../docs/flutter-integration.md) for installation, permissions and limitations. This is an initial test version, not a production release.
